# Chunksmith_modern_gui
为Chunksmith模组制作的现代化gui界面

## ✨介绍
本模组为 Chunksmith 添加一套全新现代化图形操作界面，不用记忆复杂指令，可视化操作区块相关功能。

- 可视化控制面板
- 快捷键支持
- 参数快速配置面板
- 适配 Forge 1.20.1

## 📦环境要求
- Minecraft：1.20.1
- Mod加载器：Forge
- 前置模组：Chunksmith

## 📥安装方式
1. 安装对应版本 Forge
2. 将本模组 jar 文件放入 mods 文件夹
3. 同时安装前置模组 Chunksmith
4. 启动游戏

## 🎮使用说明
- 按下快捷键打开GUI面板
- 在面板内调整区块相关参数
- 支持指令与GUI两种操作方式
